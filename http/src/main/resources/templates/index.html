We encourage you to take a tour through the PupilID Demo!

The following steps will guide you through the credential issuance procedure showcased in this demo:

  1. Prerequisite
    Download the appropriate Wallet application according to your mobile operating system from above and install the application.
    Optionally: Also download and install the Verifier application on a second smartphone. So later you will be able to verify the PupilID held by the other smartphone.
  2. Demo PupilID
    Goto the Demo page of the website. We already generated the ID of a fictive pupil for you (Note the QR-code in the center).
  3. Scan QR-code
    Open now the Wallet app and click on "QR-code scannen" or the plus sign. A QR-scanner will appear. Use it to scan the QR-code generated in the previous step.
  4. Biometric lock
    After scanning, your fingerprint is checked, to ensure cryptographic operations are executed with the permission of the smartphone owner.
  5. Check the received ID
    In the next step, the data of the pupil's ID is previewed. The user can now decide to add the ID to the Wallet app or to discard it. Press "hinzufügen" to add the ID to the Wallet in order to proceed.
  6. View the ID
    Back on the home screen of the Wallet application, the user can scroll through all the IDs he possesses. Clicking on one ID will show its details. Further, clicking on "verifiziern" will show a QR-Code that can be scanned with the Verifier application.
  7. Invalidate an ID
    In case an invalidation of a pupil's ID is needed, a demo is shown on the Revocation page. Use the list view to filter and search for the credential to be revoked and use the "revoke" button to the right to finalize the revocation.
